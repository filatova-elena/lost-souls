# Send the reminder from Eventbrite

1. Open **https://lostsouls.door66.events/reminder-email/** and click **Copy email**.
   (No QR code in the preview? The website isn't live yet. Stop and ask.)
2. Eventbrite → your event → **Manage attendees** → **Emails to attendees** → new email.
   - **To:** all attendees
   - **Reply-to:** an address you read
   - **Subject:** `One small ritual before Lost Souls`
   - **Message:** click in the box and press **Cmd+V**. The text, button and QR code come across ready.
3. **Send a test to yourself.** Open it on your phone, tap the button, and check the QR code shows.
4. **Schedule** it for about a week before the event.

If the Message box has an HTML or source view, click **Copy HTML code** on the page and paste there instead.

Late buyers don't get it, so send it again to them later.
